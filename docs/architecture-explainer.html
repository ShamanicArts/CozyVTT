CozyVTT architecture · executable state · 20 August 2026

A tabletop application designed to adapt.

The repository is now a hexagonal modular monolith with a local extension microkernel. Human HTTP calls, Socket.IO mutations, MCP clients, controlled agents, and reviewed extensions meet at explicit application boundaries rather than writing through transport code.

The pattern is: ports-and-adapters for the application core, command/query separation for automation, a microkernel for operator-controlled extensions, and Strategy/Bridge registries for rendering and themes. It remains one self-hosted deployable application; there is no package store or marketplace.

04

The extension microkernel

Manifests describe contributions; hosts own lifecycle; bridges own execution. A descriptor alone can never become authority.

 EXEC --> AUD[Digest-only audit]

Trusted packages

Code imports only after path containment, checksum, allowlist, and signature verification. Handler IDs must exactly match manifest commands; activation owns disposal.

Sandboxed packages

Code is never imported by the server. Each call gets a fresh process with read-only package, tmpfs, no network, clean environment, and heap/output/time/concurrency caps.

Durable lifecycle and UI

Installations, state, errors, OAuth connections, rotating token hashes, and confirmations survive restart. Admins manage local package lifecycle; users approve their own campaign access.

05

Rendering and themes are runtime registries

Canvas2D stays the default adapter, but layer order, replacement, invalidation, and themes are no longer hard-coded global facts.

Per-canvas renderer host

MapRendererProvider owns a scoped host. Active trusted local packages may load a reviewed browser module through a versioned API, then register, replace, unregister, and invalidate terrain, token, and overlay layers. Every registration is lifecycle-owned and disposed on refresh or unmount; sandboxed packages cannot inject browser code.

Theme host

Semantic themes validate all required tokens and 4.5:1 contrast. Active extension themes arrive as data only, fail closed when partial, and appear in the ordinary theme picker.

07

Honest limits and next expansion points

A modular application stays understandable by keeping its extension boundary finite and explicit.

Sandbox container qualification passed. Development and production images now use Node 24 LTS plus bubblewrap. The unprivileged image passed filesystem, network, child-process, crash, timeout, output-cap, and schema-isolation tests. Compose documents the required seccomp=unconfined namespace tradeoff.

Local packages by design

Packages come from an administrator-controlled local root. There is no store or marketplace. Upgrade/rollback and extension-owned migrations remain useful unfinished operations work.

Reviewed rendering, finite UI

Trusted packages can extend or replace map layers. There is still no general React route/component injection, arbitrary CSS, or iframe plugin UI.

Map writes reject races

Mutable Map JSON fields share an atomic revision. Two writers at the same revision cannot both commit; REST returns conflict and realtime clients refresh/retry.
