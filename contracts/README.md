# Public capability contracts

`public-capabilities.json` is generated by `npm run contracts:export` in the
backend. Contract release tags use the `contracts-v*` prefix. Do not hand-edit
the generated artifact.

After three releases, run `node scripts/check-contract-stability.mjs`. The gate
fails on capability removal or a changed capability version, input schema,
output schema, or principal protocol version. Additive capabilities are allowed.
